# Credit Score Prediction & Deployment

An end-to-end machine learning project for predicting customer credit scores, covering data preprocessing, model training, evaluation, experiment tracking, and deployment.

## Project Overview

This project develops a machine learning pipeline for credit score prediction. The workflow includes data preprocessing, feature transformation, model comparison, model training, evaluation, and deployment as an interactive Streamlit application.

## Methodology

- Data preprocessing and cleaning
- Numerical feature scaling
- Categorical feature encoding
- Machine learning model comparison
- Random Forest model training
- Model evaluation
- MLflow experiment tracking
- Streamlit deployment

## Technologies

- Python
- Pandas
- Scikit-learn
- Random Forest
- MLflow
- Streamlit
